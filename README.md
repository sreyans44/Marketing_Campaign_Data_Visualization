# Marketing Campaign Analysis

This project aims to analyze customer data from a marketing campaign to extract meaningful insights that can support future marketing strategies. It was developed for the second review of a college project.

## Objective

To create insightful, clear, and interactive data visualizations using cleaned marketing campaign data. The goal is to interpret the patterns and correlations in the data, helping to guide future marketing strategies.

## Repository Structure

- marketing_campaign.csv # Raw dataset
- cleaned_data.csv # Cleaned dataset used for analysis
- Marketing_Campaign_Visualization.ipynb # Colab notebook with analysis and visualizations
- Marketing_Insights_Dashboard.pbix # Power BI dashboard file
- README.md # Project description and documentation


## Dataset

- **Source**: [Kaggle - Marketing Campaign Dataset](https://www.kaggle.com/datasets/rodsaldanha/arketing-campaign)
- **Raw File**: `marketing_campaign.csv`
- **Used File for Analysis**: `cleaned_data.csv`

## Insights and Visualizations

The analysis explores the following key areas:

1. **Age Distribution**  
2. **Income Distribution**  
3. **Children in Household**  
4. **Total Spending by Product Category**  
5. **Campaign Acceptance Comparison**  
6. **Response by Marital Status**  
7. **Correlation between Income and Total Spending** *(with interactivity)*

All visualizations and explanations are available in the notebook with a detailed walkthrough of the thought process and code.

## Notebook

- **File**: `Marketing_Campaign_Visualization.ipynb`
- Platform: [Google Colab](https://colab.research.google.com/)
- Includes data preprocessing, visualizations, and markdown cells explaining each step and insight.

## Power BI Dashboard

An interactive dashboard built using Power BI provides filters and slicers to explore:

- Age, income, and marital status  
- Campaign response behavior  
- Customer segmentation

- **File**: `Marketing_Insights_Dashboard.pbix`
- Tool: Power BI Desktop

## Tools Used

- Python (Google Colab)  
- Libraries: Pandas, Seaborn, Matplotlib, Plotly  
- Power BI  
- GitHub (for project submission)

## How to Use

1. Clone the repository.  
2. Open the notebook in Google Colab.  
3. Make sure `cleaned_data.csv` is uploaded in the Colab environment.  
4. Run the notebook cells to reproduce the visualizations and insights.  
5. Open the `.pbix` file in Power BI Desktop to explore the dashboard.
