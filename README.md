# Marketing Campaign Analysis

This project aims to analyze customer data from a marketing campaign to extract meaningful insights that can support future marketing strategies. It was developed for the second review of a college project.

## Objective

The primary goal is to create effective and visually clear data visualizations based on cleaned marketing campaign data. These visualizations help tell a compelling story about customer demographics, behavior, and responses to past marketing efforts.

## Dataset

- **Source**: [Kaggle - Marketing Campaign Dataset](https://www.kaggle.com/datasets/rodsaldanha/arketing-campaign)
- **File Used**: `cleaned_data.csv` (included in this repository)

## Insights Covered

The following key areas were explored during the analysis:

1. Age distribution of customers  
2. Income distribution  
3. Number of children in households  
4. Total spending by product category  
5. Comparison of accepted marketing campaigns  
6. Campaign response by marital status  
7. Correlation between income and total spending (interactive)

Each visualization is supported with clear explanations in the notebook, walking through the reasoning behind the choices made and insights derived.

## Power BI Dashboard

An interactive dashboard was created using Power BI for dynamic data exploration.

- **File**: `Marketing_Insights_DataVisualization_PowerBI_Dasboard.pbix` (included in this repository)

This dashboard includes filters, slicers, and storytelling visuals that allow users to explore campaign responses and customer behavior across various dimensions such as age, income, and marital status.

## Tools Used

- Google Colab (Python, Pandas, Matplotlib, Seaborn, Plotly)  
- Power BI Desktop (for interactive dashboard)  
- GitHub (for version control and submission)

## How to Run

1. Clone this repository.  
2. Open the notebook `Marketing_Analysis_Visualization.ipynb` using Google Colab.  
3. Ensure the `cleaned_data.csv` file is available in the same directory.  
4. Execute the notebook cells step-by-step to generate the visualizations.  
5. Open the Power BI file `Marketing_Insights_DataVisualization_PowerBI_Dasboard.pbix` in Power BI Desktop to explore the interactive dashboard.
